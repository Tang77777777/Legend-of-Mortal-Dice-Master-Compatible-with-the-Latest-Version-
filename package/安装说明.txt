骰子大师 64 位修复包

适用情况
游戏更新后，旧版骰子大师完全没有菜单或 BepInEx 日志。

安装方法
1. 退出游戏和 Steam 中正在运行的游戏进程。
2. 打开本压缩包，复制里面的全部内容。
3. 粘贴到 LegendOfMortal 游戏根目录，也就是能看到 Mortal.exe 的文件夹。
4. Windows 提示覆盖时选择“替换文件”。
5. 启动游戏。主界面左上角出现 Dice Log Output 即表示加载成功。

重要说明
- 本修复包使用 64 位 Unity Mono BepInEx 加载器。
- 不要把内容复制到 Mortal_Data 文件夹里面。
- 如果玩家已经安装了其他 BepInEx 插件，解压时只覆盖同名运行时文件，其他插件文件夹会保留。
- 建议安装前备份游戏根目录中的 BepInEx、winhttp.dll、doorstop_config.ini 和 .doorstop_version。

故障判断
- 游戏根目录必须存在 winhttp.dll，并且它必须是 64 位文件。
- 成功启动后会生成 BepInEx\LogOutput.log。
- 日志中应看到“Process bitness: 64-bit (x64)”和“Loading [DiceMaster 1.0.0]”。

本包修复的是加载器位数不匹配问题：原包 winhttp.dll 为 32 位，而更新后的游戏为 64 位。DiceMaster.dll 本体保持原版本。

窗口过小修复
- 本包额外包含 BepInEx\plugins\DiceMasterUiFix.dll。
- 它会把骰子大师局内窗口的最小缩放提高到 0.75，解决高分辨率下窗口和文字过小的问题。
- 启动一次游戏后会生成 BepInEx\config\DiceMaster.UiFix.cfg。
- 如果仍然觉得文字小，将其中 MinimumScale 改为 1.0 或 1.25，保存后重新启动游戏。
