# 原始来源与修改说明

原始模组页面：<https://mod.3dmgame.com/mod/210536>

本仓库不是原始 DiceMaster 项目的官方仓库。仓库中的 `DiceMaster.dll` 来自用户提供的原始模组包，用于让玩家在当前游戏版本继续使用原功能。

本次新增和修改的内容：

- 使用 64 位 Unity Mono BepInEx 加载器适配更新后的游戏。
- 新增 `DiceMasterUiFix.dll`，修复局内修改器窗口过小和文字难以阅读的问题。
- 保留原始 DiceMaster 功能和 DLL 版本，不对原始功能逻辑做改写。

请根据原始页面的授权和发布规则使用、转载或再发布原始模组文件。
