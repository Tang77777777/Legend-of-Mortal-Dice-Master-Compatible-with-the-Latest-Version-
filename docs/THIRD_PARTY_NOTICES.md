# 第三方组件说明

本仓库的 `package/` 包含用于加载插件的 BepInEx Unity Mono 组件。BepInEx 是开源项目，许可和源代码见：

- <https://github.com/BepInEx/BepInEx>
- <https://github.com/BepInEx/BepInEx/blob/master/LICENSE>

`package/BepInEx/plugins/DiceMaster/DiceMaster.dll` 来自原始 DiceMaster 模组，来源页面为 <https://mod.3dmgame.com/mod/210536>。该 DLL 未被本仓库重新编译；其作者、版权和原页面规定继续适用。

`DiceMasterUiFix.dll` 是本仓库新增的兼容补丁，源码位于 `src/DiceMasterUiFix/`。
